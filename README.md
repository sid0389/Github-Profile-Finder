# GitHub Profile Finder

A responsive web application to search GitHub users and explore their public profiles and repositories using the GitHub REST API.

## Features

- Search GitHub users by username.
- View profile details, including avatar, bio, followers, following, and public repository count.
- Display up to six recently updated public repositories.
- View repository descriptions, programming languages, stars, forks, and last-updated dates.
- Switch between dark and light themes.
- Handle invalid usernames, loading states, and API errors.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub REST API
- Fetch API and async/await

No API key or backend server is required for basic access to public GitHub profile and repository data.

## What I Learned

- Fetching data from REST APIs using JavaScript.
- Using async/await for asynchronous operations.
- Updating webpage content dynamically using the DOM.
- Handling loading states and API errors.
- Building a responsive interface with dark and light themes.
